# GPT Bro — генератор картинок с памятью

Локальное приложение для одного человека. Оно создаёт картинки по описанию, помогает улучшать описания и поддерживает разговор. Имя, последние реплики, предпочитаемый стиль и созданные изображения сохраняются между запусками.

Картинки создаёт [SD-Turbo](https://huggingface.co/stabilityai/sd-turbo) через Diffusers. Разговор ведёт [Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct) через Transformers. **Powered by Stability AI.** У SD-Turbo есть отдельная [лицензия](https://huggingface.co/stabilityai/sd-turbo/blob/main/LICENSE.md); ознакомьтесь с ней перед распространением приложения.

## Запуск

Нужны Python 3.10 или новее, интернет для первой загрузки моделей и свободное место на диске. Видеокарта ускорит создание картинок. На компьютере без видеокарты желательно от 16 ГБ оперативной памяти; генерация может быть медленной.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

На Windows вместо `source .venv/bin/activate` используйте `.venv\Scripts\activate`. Если на Linux нет видеокарты NVIDIA, можно перед установкой зависимостей поставить компактную CPU-сборку PyTorch: `pip install torch --index-url https://download.pytorch.org/whl/cpu`. Откройте адрес, который приложение покажет в терминале (по умолчанию `http://127.0.0.1:7860`). Приложение слушает только локальный компьютер и не создаёт публичную ссылку.

Первая генерация картинки скачает SD-Turbo, а первое сообщение в чате — Qwen. Загрузка может занять время и требует доступа к Hugging Face. Ключ API не нужен. Если модель уже есть в локальном кэше Hugging Face, она будет использована повторно.

## Как пользоваться

1. В разделе **Разговор** укажите имя и, если хотите, заметки о себе. Имя — локальная настройка, а не проверка личности.
2. Напишите помощнику об идее или прежней картинке. Он получает последние реплики, подходящие по словам старые сообщения и сведения о трёх последних генерациях.
3. В разделе **Создать картинку** опишите изображение. Можно добавить любимый стиль и нажать **Запомнить стиль**, либо создать картинку — успешная генерация тоже сохранит стиль.
4. Кнопка **Улучшить описание с ИИ** предлагает английский вариант запроса. Проверьте его перед генерацией. Английские описания могут работать лучше с SD-Turbo.
5. Сохранённую картинку и её настройки можно вернуть из истории. `Seed` позволяет повторить тот же случайный выбор; `-1` выбирает новый seed.

## Память и ограничения

История разговора и заметки о себе хранятся в `data/memory.sqlite3`, изображения — в `data/images/`. Папка `data/` исключена из Git, поэтому личные сообщения и картинки не попадают в коммиты. На системах с правами POSIX эти файлы доступны только владельцу. Чтобы хранить данные в другом месте, задайте переменную среды `APP_DATA_DIR` перед запуском; выберите папку **за пределами Git-репозитория**.

Приложение рассчитано на **одного локального пользователя**. Все, кто имеют доступ к запущенному интерфейсу или папке `data/`, видят одну и ту же память. Для публичного доступа и нескольких людей понадобятся вход в аккаунт и отдельная память для каждого. Текущая структура базы уже помечает записи профилем, чтобы это можно было добавить позже.

Память сохраняет разговор и параметры картинок, но **не переобучает модели и не меняет код сама**. В запрос к разговорной модели отправляется ограниченная часть недавней истории и до четырёх подходящих старых сообщений; поиск старых сообщений по совпадению слов не идеален. Кнопка **Удалить историю разговора** удаляет реплики, но оставляет изображения и заметки о себе. Для полного сброса локальной памяти остановите приложение и удалите папку `data/`.

Разговорная модель небольшая и может ошибаться. Создание картинки запускается отдельной кнопкой; слова в чате сами по себе не создают изображение.
